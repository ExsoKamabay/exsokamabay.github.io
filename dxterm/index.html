Open-source Android terminal

Linux on Android. No root required.

dracxterm gives you a working shell immediately, then installs Debian 13 or Kali Linux inside app storage when you want a full distribution. No account, ads, analytics, or trackers.

Pocket Linux workspace

A real terminal first. A full Linux environment when you need it.

The terminal engine, ANSI/VT parser, screen buffer, PTY handling, and UTF-8 rendering are implemented in C++. The Android interface is written in Kotlin.

01 / ROOTLESS

Debian and Kali without rooting Android

Install Debian 13 or Kali Nano, Minimal, or Full inside the app. Use apt, dpkg, sudo, and familiar Linux tools without changing the phone system.

02 / TERMINAL

Built for interactive command-line work

Truecolor, UTF-8 and CJK text, scrollback, alternate screen, selection, search, clipboard, bracketed paste, and mouse tracking are supported.

03 / WORKSPACES

Five independent sessions

Each workspace keeps its own shell, PTY, directory, and history. Sessions stay alive while you switch apps, and the extra key row keeps Ctrl, Alt, Esc, arrows, and navigation close.

04 / PRIVATE

No account, ads, analytics, or telemetry

Network access is used only for downloads you request. Distribution images are fetched over HTTPS and checked against pinned SHA-256 digests before extraction.

On-device proof

From first launch to a multi-session Linux workspace.

Install safely

Download, verify, install.

Each GitHub release includes a universal APK for ARM64 and x86_64 plus a matching SHA-256 file. Existing installations can be upgraded without deleting the Linux root filesystem or home directory.

Android will ask you to allow installation from your browser or file manager because the APK is distributed outside an app store.

# Download both files from the latest GitHub release
$ sha256sum -c dracxterm-1.0.6-vc6-release.apk.sha256
$ adb install -r dracxterm-1.0.6-vc6-release.apk

Turn your Android device into a private, rootless Linux command line.
