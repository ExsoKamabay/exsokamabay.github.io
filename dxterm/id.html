Terminal Android open-source

Linux di Android. Tanpa root.

dracxterm langsung memberi Anda shell yang siap dipakai, lalu memasang Debian 13 atau Kali Linux di ruang aplikasi saat Anda memerlukan distro lengkap. Tanpa akun, iklan, analitik, atau pelacak.

Unduh APK terbaru Lihat kode di GitHub
  • Android 7.0+
  • ARM64 dan x86_64
  • GPL-3.0
  • Versi 1.0.6

Ruang kerja Linux di saku

Terminal sungguhan sejak awal. Linux lengkap saat dibutuhkan.

Mesin terminal, parser ANSI/VT, buffer layar, penanganan PTY, dan render UTF-8 dibuat dengan C++. Antarmuka Android ditulis dengan Kotlin.

01 / ROOTLESS

Debian dan Kali tanpa me-root Android

Pasang Debian 13 atau Kali Nano, Minimal, maupun Full di dalam aplikasi. Gunakan apt, dpkg, sudo, dan perkakas Linux tanpa mengubah sistem ponsel.

02 / TERMINAL

Dibuat untuk kerja baris perintah interaktif

Truecolor, UTF-8 dan teks CJK, scrollback, alternate screen, seleksi, pencarian, clipboard, bracketed paste, dan mouse tracking sudah didukung.

03 / WORKSPACE

Lima sesi yang berdiri sendiri

Setiap workspace memiliki shell, PTY, direktori, dan riwayat sendiri. Sesi tetap hidup saat Anda pindah aplikasi, sementara baris tombol menyediakan Ctrl, Alt, Esc, panah, dan navigasi.

04 / PRIVASI

Tanpa akun, iklan, analitik, atau telemetri

Jaringan hanya dipakai untuk unduhan yang Anda minta. Image distro diambil lewat HTTPS dan diperiksa dengan SHA-256 yang sudah dipin sebelum diekstrak.

Bukti dari perangkat

Dari peluncuran pertama hingga ruang kerja Linux multi-sesi.

Pasang dengan aman

Unduh, periksa, pasang.

Setiap rilis GitHub menyediakan APK universal untuk ARM64 dan x86_64 beserta berkas SHA-256. Pemasangan lama bisa diperbarui tanpa menghapus root filesystem Linux atau isi direktori home.

Android akan meminta izin memasang dari browser atau pengelola berkas karena APK dibagikan di luar toko aplikasi.

# Unduh kedua berkas dari rilis GitHub terbaru
$ sha256sum -c dracxterm-1.0.6-vc6-release.apk.sha256
$ adb install -r dracxterm-1.0.6-vc6-release.apk

Jadikan perangkat Android Anda terminal Linux privat tanpa root.
